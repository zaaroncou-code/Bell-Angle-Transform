Bell Angle Transform

This repository contains the paper and source files for:

The Bell Angle Transform: A Normalized Framework for Bell-Like Functions and Tail Behavior

Author: Zachary A. Coughlin

The paper introduces the Bell Angle Transform and the Bell Angle, a way of comparing normalized bell-like functions using a single scalar value. It also includes the Bell Vector, which keeps more of the shape information than the Bell Angle alone.

The paper looks at different bell-shaped families, heavy-tailed examples, mixtures, reference values, and approximate distribution comparison.
